# Pausa para refletir

Vídeos da conta do TikTok @pausa.para_refletir, servidos ao Buffer pelo endereço "raw" deste repositório.

- `videos/dia-NN.[dan].mp4`: manhã (d, 06h), almoço (a, 11h30) e noite (n, 19h), horário de Brasília.
- `textos.json`: falas e legendas de cada dia.
- `publicar_pausa.py`: agenda no Buffer os posts de um dia. Usa a chave `BUFFER_API_KEY_PAUSA` do ambiente, nunca no código.

Contagem: 02/11/2026 = Dia 1 (só a noite), 03/11/2026 = Dia 2, e assim por diante.
